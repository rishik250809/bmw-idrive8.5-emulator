Checks contact GitHub only when requested and are cached for five minutes. Nothing is downloaded or installed automatically. This updates the emulator, not BMW firmware.

How to install an update

In Terminal, open your emulator project folder and run:

bash update.sh

This pulls your tracked branch (fast-forward only), copies the source into Lima, and restarts your current vehicle profile. Local changes or a detached release tag require manual review. Coding, presets, mocks and imported BMW files are kept. For a ZIP download, get the new project files and run its install.sh against your existing VM.

CAFD → preset converter

Paste a JSON name/value object, {"overrides":{…}}, or {"entries":[{"uuid":"0x…","value":1}]}. Explicit values are converted through your firmware dictionary; numeric enums become labels. Raw binary CAFD/NCD decoding and donor defaults are not supported.

CAFD dictionary & entry builder

Read from private firmware. Only verified meanings are described. Choose a value and add it to the editor; values are never inferred from metadata.
